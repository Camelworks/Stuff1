# 🎂 Itamar Runs to the Fridge - Birthday Game! 🎮

A fun browser-based game created for Itamar's 13th birthday!

## How to Play

### Starting the Game
1. Simply open `index.html` in any web browser (Chrome, Firefox, Safari, Edge)
2. Click "START GAME" button
3. Help Itamar reach the fridge!

### Controls
- **SPACE BAR** or **UP ARROW** - Jump
- Works on mobile too - just tap the screen!

### Game Rules
- Jump over obstacles (boxes and spikes)
- Each obstacle you pass gives you **13 points** (because it's his 13th birthday! 🎉)
- You have **3 lives** - each collision costs one life
- Reach **260 meters** to get to the fridge and win!
- The game gets faster as you progress!

## Features
- 🎮 Geometry Dash-style gameplay

- 📱 Works on computers and mobile devices
